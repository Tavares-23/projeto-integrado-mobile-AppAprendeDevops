# AppAprendeDevops

## 1. Apresentação do Projeto

O AppAprendeDevops é um projeto fictício de aplicativo
mobile educacional, desenvolvido com o objetivo de
ensinar alunos a compreender e exercer o papel de
Scrum Master.

## 2. Objetivo

Oferecer um ambiente de aprendizagem simples,
dinâmico e interativo, utilizando exemplos práticos,
simulações e atividades para facilitar o entendimento
da metodologia Scrum.

## 3. Público-alvo

- Estudantes de Análise e Desenvolvimento de Sistemas.
- Pessoas interessadas em metodologias ágeis.
- Iniciantes que desejam aprender Scrum.
- Futuros Scrum Masters.

## 4. Funcionalidades propostas

- Aulas sobre fundamentos do Scrum.
- Conhecimento sobre os papéis do Scrum.
- Simulação de reuniões Daily Scrum.
- Exercícios e questionários interativos.
- Simulação de situações do cotidiano de um Scrum Master.
- Acompanhamento do aprendizado.

## 5. Tecnologias e Ferramentas

- Plataforma proposta: Android.
- Linguagem de desenvolvimento: Kotlin (proposta).
- Versionamento: GitHub.
- Metodologia de trabalho: Scrum.
- Gestão de versões: Git Flow simplificado.
