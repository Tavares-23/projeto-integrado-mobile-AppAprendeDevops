# Arquitetura do Sistema — AppAprendeDevops

## 1. Visão geral

O AppAprendeDevops é um projeto acadêmico fictício de aplicativo educacional para dispositivos Android. Seu objetivo é ensinar conceitos da metodologia Scrum de maneira simples, dinâmica e interativa.

O público-alvo inclui estudantes de Análise e Desenvolvimento de Sistemas, iniciantes em metodologias ágeis e pessoas interessadas em atuar como Scrum Master.

## 2. Tecnologias propostas

- Plataforma: Android.
- Linguagem de programação: Kotlin.
- Controle de versão e documentação: GitHub.
- Metodologia de desenvolvimento: Scrum.
- Gerenciamento de branches: Git Flow simplificado.

## 3. Organização da arquitetura

O projeto prevê quatro módulos principais:

- Interface do usuário: telas de navegação, aulas e atividades.
- Módulo de aprendizagem: conteúdos sobre Scrum, papéis e responsabilidades.
- Módulo de atividades: questionários e simulações práticas.
- Módulo de progresso: acompanhamento da evolução do estudante.

## 4. Funcionalidades previstas

1. Apresentação dos conceitos fundamentais do Scrum.
2. Explicação dos papéis e responsabilidades.
3. Simulação de reuniões Daily Scrum.
4. Questionários interativos.
5. Simulações de situações enfrentadas por um Scrum Master.
6. Acompanhamento do progresso de aprendizagem.

## 5. Organização do repositório

- /docs: documentação e diagramas do projeto.
- /src: estrutura destinada ao código-fonte.
- /assets: recursos estáticos.
- /tests: estrutura destinada aos testes.
- /.github: configurações e recursos de apoio ao fluxo de trabalho.

## 6. Situação atual

Este é um projeto acadêmico fictício, desenvolvido com finalidade de aprendizagem e documentação de práticas DevOps. A arquitetura apresentada é uma proposta conceitual. Não existe aplicativo funcional implementado nesta etapa.
